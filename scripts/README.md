# Scripts y automatización

Guardar los scripts Bash o PowerShell y playbooks Ansible elaborados por el equipo.

## Organización
- T08-preparacion: automatización de una configuración ya probada manualmente.
- T09-copias: ejecución y verificación de copias y restauraciones de laboratorio.
- T11-comprobaciones: pruebas de red, web, base de datos y monitorización.

## Documentación obligatoria de cada script
Indicar objetivo, sistema y versión probados, dependencias, permisos necesarios, parámetros, forma de ejecución, resultado esperado y procedimiento de reversión cuando corresponda.

No incluir secretos. Revisar el código antes de ejecutarlo y probarlo primero en las máquinas del laboratorio. Esta carpeta contiene una guía inicial; todavía no hay scripts de despliegue implementados.
