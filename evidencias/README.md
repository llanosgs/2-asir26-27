# Evidencias de funcionamiento y entregas

Guardar capturas y registros de pruebas de laboratorio, sin datos personales ni secretos.

## Identificación
Usar el formato TXX-fecha-descripcion.ext, por ejemplo T06-2026-11-16-web-accesible.png. Cada evidencia debe indicar tarea, fecha, procedimiento, resultado esperado, resultado obtenido y autor.

## H1: infraestructura base
- T01: enlace al repositorio y documentación inicial.
- T02: máquinas y redes virtuales.
- T03: sistema operativo, red y acceso SSH.
- T04: reglas del firewall y pruebas de acceso.

## H2: implantación completa
- T05: ejecución del entorno de contenedores.
- T06: acceso a la web desde un cliente.
- T07: conexión a la base de datos con permisos limitados.
- T08: ejecución de la automatización y verificación.
- T09: copia y restauración comprobada.
- T10: monitorización y alerta de prueba.
- T11: informe de pruebas integradas e incidencias resueltas.

Enlazar los archivos desde las issues y tarjetas de GitHub Projects. La entrega se considera validada cuando el docente revisa las evidencias y registra su conformidad. Todavía no se han generado evidencias técnicas.
